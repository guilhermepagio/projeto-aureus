# Histórico de specs avulsas

Specs concluídas que não pertencem a um épico, arquivadas por mês de criação (`AAAA-MM`). Specs em andamento permanecem na área ativa de `implementation-artifacts/`.

Ao arquivar uma spec, preserve seu nome e conteúdo histórico, ajuste os links relativos e referências externas e acrescente uma entrada neste índice. Todas as specs abaixo estão registradas como `done`.
